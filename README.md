# DAT1030 Data Analysis Project

## Problem
The goal of this project was to analyze the Video Game Sales dataset to identify trends in global sales and critic scores using data transformation, aggregation, and visualization.

## Dataset
Video Game Sales Dataset

The original dataset was provided as part of the DAT1030 course activities.

## Tools Used
- Microsoft Excel
- SQL

## Steps Performed
1. Loaded the dataset.
2. Applied data transformations.
3. Created SQL aggregation queries.
4. Built histograms and dashboard charts in Excel.
5. Compared Sports and Shooter games using the visualization results.

## Insights
The analysis showed that Sports games had a slightly higher average critic score than Shooter games. Histograms also helped visualize the distribution of global sales across both genres.
